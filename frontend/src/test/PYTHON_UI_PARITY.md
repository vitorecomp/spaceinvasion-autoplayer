## Phase 6 Deletion & Decision D7 Prerequisites

1. **Retain backend/bridge assertions during Phase 6 Python test cleanup**: Several of the 58 tests above combine a Node-VM UI check with server-side bridge, API, config, or persistence assertions (for example: `test_ag_e2e_03_explicit_apply_persists_across_bridge_restart` bridge-restart persistence, `test_t4_07_api_restart_sqlite_wal_config_and_ui_hot_reload_continuity` SQLite/Postgres restart continuity, and the API/config/runtime halves of `test_adv_t5_17_m5_r7_ui_race_and_corrupt_pct_api_unicode_and_lifecycle_parity` and `test_adv_t5_18_m5_r8_keepalive_redaction_arabic_float_mlp_horizon_and_ui_guards`). When deleting Node-VM UI blocks in Phase 6, retain or migrate those server-side assertions into Python API/integration tests rather than deleting the entire test methods/files wholesale.
2. **Additional D7 prerequisite beyond `run_ui_in_node`**: Before untracking the compiled `spaceinvasion/ui/` bundle (Decision `D7`), also port or remove the remaining **non-Node** Python tests that statically read or HTTP-fetch `spaceinvasion/ui/{index.html,styles.css,app.js}` in `tests/unit/test_ui.py` and `tests/unit/test_api_and_commander.py`.
